AUTO-UPDATING INSTAGRAM REELS

1. Upload the full website to a PHP-enabled web host. Keep index.php in the website root.
2. Put each new video file (.mp4, .mov, or .webm) into assets/insta-reels/ .
3. Refresh the website. The new video is automatically included; no HTML editing or manifest update is needed.

IMPORTANT: This version uses PHP, so it will NOT auto-scan the folder on static-only hosting such as GitHub Pages. Use a PHP-enabled host (for example, cPanel hosting with PHP) or ask for a static-hosting build workflow.
